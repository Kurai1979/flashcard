# Goose migrations

This folder stores SQL migrations for Goose.

## Naming

Use timestamp-based names generated by Goose:

```bash
goose -dir db/migrations create create_flashcards_table sql
```

## File format

```sql
-- +goose Up
-- SQL in section 'Up' is executed when this migration is applied.

-- +goose Down
-- SQL in section 'Down' is executed when this migration is rolled back.
```
